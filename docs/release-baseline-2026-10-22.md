## 新版版本查询

```bash
# 通过已有操作者认证访问后端；本机代理会转发此路径。

# 只查询本机代理自身，不访问云端。
curl -fsS http://127.0.0.1:18787/api/local/release
```

远程 HTTPS 的 `/api/release` 沿用 Caddy 操作者认证，不为外部调用方令牌开放管理入口。上述本机路径仅用于已信任的本机代理，不应为免登录而开放公网端口。

返回的 `role` 分别为 `console-api` 和 `local-proxy`；`release.source` 包含 `revision/branch/dirty`，未知为 `null`，不假定干净。`releaseId/packagedAt` 来自安装器清单，`observedAt` 表示进程启动时读取时间。`entrypoints` 是后端、代理、锁文件及页面入口的 SHA-256，不是全目录完整性证明，也不表示特性已通过业务验收。快照固定到进程启动，`Cache-Control: no-store` 避免客户端旧缓存冒充当前结果。

旧版返回 404 时应记录旧版本，不能把页面能打开或包版本 `0.1.0` 当作已部署证据。源码导出没有 `.git` 和来源清单时，提交与分支保持未知；安装器不伪造来源。发布来源应使用已验收的干净提交或包含明确来源清单的导出，保留关键文件核对。
