# 个人计划试运行门禁验收（2026-09-28）

## 本轮范围

- 个人流程增加显式试运行；由用户确认模型额度后，按定时计划相同的只读任务提示启动独立 Codex 会话。
- 服务端保存试运行运行 ID、任务正文 SHA-256 和人工确认时间。启用计划必须具备当前正文的确认记录；失败、空结果或有本地 diff 的运行不能确认。
- 修改任务正文自动暂停计划并使原确认失效；仅修改名称不暂停。页面展示未测试、待确认、已确认及内容过期状态，可打开对应会话核对。
- 试运行或计划运行中观察到非只读 MCP 工具调用，即使工具报告成功且模型回合正常结束，也标记为待核对；计划据此暂停，不自动重试。
- 试运行本身仍可能消耗模型额度；模型回合完成和人工确认不保证连接器没有外部副作用。只读文件沙箱不是已连接服务的权限边界。

## 剩余差距

- 试运行是一个有成本的真实模型回合，无法代替连续日常使用验收；本地自动化仅用模拟服务，不扣真实模型额度。
- 已连接服务可能仍暴露写入工具。无人值守任务若需使用连接器，应先实现可验证的工具级只读限制，而不能仅依靠提示词或本地文件沙箱。
- 本地 diff 只在 Git 工作区可检测；默认个人目录不是 Git 仓库，不能把没有 diff 视为完整的外部动作或文件写入证明。
- 历史运行记录按总量裁剪；确认元数据会保留，但很旧的试运行完整会话未必仍可在控制台打开。
