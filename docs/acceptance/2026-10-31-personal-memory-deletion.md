原固定场景 E14 缺少“删除后真实模型如何回答”的证据。本轮从 main `308cc86` 独立推进，不携带仍为草稿的日程 PR #52，不读写真实邮箱、日历或正式个人事实。

## 删除交互与 Review

实际内置浏览器能新增虚构事实，但旧 `window.confirm` 删除操作随后卡住；后端只读回查确认记录未删除。工具未取得确认框，也无法关闭旧标签；尝试只读检查 Codex 原生窗口被工具安全策略拒绝，已停止该途径，没有换别名或改安全设置。

代码复用已有候选清理的应用内 `<dialog>`，事实和候选只保留一个删除处理器，删除了重复逻辑。默认焦点为取消，Escape/取消不请求删除；确认固定对象编号和版本，变化后拒绝并刷新，不自动重试，不清空其他未提交输入。事实删除说明不再暗示抹除旧对话或已开始任务；清理候选仍不删除已接受事实。

Review 另修正已接受候选的历史说明：对应事实被删除后，保留“曾接受”记录，但明确该事实已不在当前资料中，不再错误引导查看不存在的当前事实；不会因此重新激活或重建偏好。
