# 生产 API 图片与文件闭环验收

日期：2026-10-30，Asia/Shanghai。

## 结论与范围

在 EC2 正式控制台 `1936ccb4f295b46ebed2b0988363fcf02cd86470`、Codex CLI 0.165.0 上，使用单个已授权的手动测试自动化和一枚一小时替代令牌，完成一次 `gpt-6-sol / medium` 回合。虚构 Markdown 和 PNG 输入、结构化 JSON、报告文件、独立 Python 下载、同键找回、用量及撤销链路通过。

这是生产外部 API 的一个真实交付样例，不是全部 M2-M5 退出证明。客户端是 EC2 上独立的 Node/Python 进程，通过正式 HTTPS 地址访问；它不等于另一台机器或多租户安全隔离。没有更换线上应用代码或默认模型，也没有发送邮件、改日历、新增 AWS 资源或重置额度。

原生实际条目只有用户消息、推理、助手消息和命令执行，没有连接器、协作、联网搜索或图片生成条目。这是本次回合的证据，不是共享机器不可访问其他文件的保证；当前仍只面向受信任调用方。
