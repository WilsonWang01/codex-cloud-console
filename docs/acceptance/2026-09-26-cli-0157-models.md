日期：2026-09-26。目标：升级云端 CLI，前端支持当前账号新增模型；保留账号登录、会话、任务及默认 `gpt-5.6-terra / medium`。

## 变更

- npm 官方 `@openai/codex` 的 `latest` 为 `0.157.1`，升级目标选稳定版，不采用 `0.159.0-alpha.4`。
- 仓库协议定义按 `0.157.1` 重新生成，schema 检查基线同步更新。新协议移除的 `thread/rollback` 未被业务代码使用，新增可选字段不破坏现有请求。

- 模型菜单打开、页面重新可见时主动刷新；页面可见期间定期查询。请求序号避免迟到的旧结果覆盖新列表。
- 未写死 GPT-6 型号作为所有账号可用选项，不强制改默认模型，不重写现有会话或自动化配置。

依据：[官方 App Server 模型发现接口](https://learn.chatgpt.com/docs/app-server#list-models-modellist)要求按账号返回的模型和推理强度渲染选择器；[Codex CLI 文档](https://learn.chatgpt.com/docs/codex/cli)。
