## 修复与口径

- 同步调用出现 504/499/502 时可能已经保存任务。受理数改用关联运行 ID 和非重放证明，不再只看 2xx；提交、受理、同键重放、能力查询、结果查询和取消分别展示。
- 任务的明确失败、已取消、中断待核对、处理中/排队和未知状态分开。成功率只含完成与明确失败，未知用量占比只含终态任务；回合数只统计已取得会话/回合标识的去重记录，不当作账单。
- 全筛选窗口统计有效请求耗时，精确计算 P50/P95 并列样本数。任务排队与后台处理分开；处理包含准备和收尾，中断恢复时间不当作实际结束时间。缺失、负数耗时和无样本不填 0。
- 指标文件逐行读取，不再一次加载整个文件及全部请求对象。仅保留最近 500 条请求，任务明细最多 200 条；汇总不受这两个列表上限影响。精确分布的内存仍随不同耗时值增长，没有无限日志容量承诺。
- 只返回指标白名单字段；损坏行计数、读取中消失的文件明确提醒，其余读取错误明确失败。普通文件检查、拒绝符号链接/FIFO、请求取消与句柄关闭覆盖本次读取；不另建数据库或计量服务。
- 页面复用既有 15 秒超时和中文代理错误处理。令牌范围只在服务器配置成功加载后显示；新令牌未关闭前禁止再次创建。创建结果不明确时提示先刷新核对，不自动重试或自动撤销；到期状态不再显示启用。
- 旧后端没有提供的新统计显示 `--` 或明确缺失。所有调用错误包含流式逻辑错误；分类按已记录状态粗分，不能当作根因分析。鉴权前失败和部分限流拒绝未记录，不宣称完整流量或财务账单。
