## 交付与 Review

- 后端 `GET /api/release` 与本机代理 `GET /api/local/release` 分别报告启动时版本。包含提交、分支、未提交改动标记、Node、来源清单时间及固定入口摘要，不返回磁盘目录、凭据、Git 变更文件列表或业务数据。不访问模型和云管理 API。
- 快照在进程启动时生成，而不是每次请求重新读磁盘；缺少 Git、旧导出和不支持的清单版本明确为未知。入口摘要只证明相应文件，不声称是完整发布校验或业务能力证明。
- 安装器沿用既有新目录构建、切换前门禁、严格健康及失败回退，只增加来源清单。旧清单不直接复制，重新生成本次发布 ID；不迁移或清理业务状态，不引入新依赖、数据库和 AWS 资源。
- `README`、架构、路线图、后端接入均指向同一基线。修正“尚无 OpenAI 流式聊天”的过时描述，明确既有协议子集和未来能力发现/结构化输出/文件交付之间的区别；旧验收不自动成为当前上线证明。
- 没有整批替换包版本号或强行更新 CLI。EC2 现有 CLI 与仓库固定 schema 都是 0.157.1；本轮只核对兼容性，不据此声称是官方最新版本。默认模型和已有任务选择不变。
