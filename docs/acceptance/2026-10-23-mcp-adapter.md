# A04.2 MCP 薄适配验收

日期：2026-10-23，Asia/Shanghai。状态：本地实现与验收通过，等待本轮提交及 Linux CI；尚未安装到生产客户端。用法见 [MCP 接入说明](../mcp-integration.md)。EC2 后端、既有本机代理和客户端权限均未修改。

## 交付范围

- 官方 MCP SDK 的 stdio 进程，一次固定绑定一个源站、独立令牌和自动化。默认五个只读工具；显式启用执行后增加提交/续接和取消，共七个工具。
- 提交带调用方预先保存的业务事件 ID，复用既有 HTTP 客户端与持久幂等；不建立本地任务队列或第二套执行、审批与计量引擎。
- 状态摘要明示裁剪；完整正文/结构化 JSON 可按返回偏移拼接。私有文件先验证完整大小与 SHA-256，再返回 Base64 分块；小图片可返回标准 MCP 图片内容块。
- MCP 本地取消/断开只停止等候，不自动取消云端任务；取消工具显式调用。固定两项在途操作、30 秒调用期限、10 秒 HTTP 尝试期限，沿用一次同键有限重试。
- 没有 URL/路径/权限/任意命令工具参数，不回退管理员登录，不跟随下载跳转，不向本机文件系统写下载内容，不把输入或原始错误写日志。

相对于上一版 Mac 89,422,414 字节运行依赖，增加约 13.3 MiB、三个实际生产包（SDK server/core 和 Zod）。这是使用官方协议实现而非自制 JSON-RPC 的明确成本；没有将测试客户端及其辅助依赖带入生产包。当前 EC2 没有安装这批包或增加常驻进程；客户端安装即可使用已兼容 HTTP 后端。

本轮没有前端改动，协议与工具调用通过独立 SDK 客户端验证，不以旧网页截图代替 MCP 客户端体验验收。没有注册到当前 Codex 环境，避免递归调用与未确认的权限扩张；没有把未接入的 Muse/Today/Grok Bot 算作实际已兼容。

## Review

本轮为自审，不冒称独立人工或 subagent review。复用既有输入校验、作用域身份、HTTP 请求期限、幂等和文件完整性校验。只有 MCP 结果分页、脱敏错误、进程内准入及工具注册留在适配模块。

自审修正：繁忙拒绝显式 `isError:true` 并保留事件 ID；超界偏移拒绝而非伪装完整空结果；启动前仅验证四项配置，不额外创建一个闲置 MCP 实例；摘要计数避免反复转换。重试不产生新事件 ID，读取不启动推理，客户端断开不隐式撤销真实动作。SDK 取消与超时返回未知执行状态时保留原编号，不能承诺云端任务已停止。

完整 `run.structuredOutput.data` 不塞进状态摘要；从受限输出接口分段取得完整 JSON。大文件每段会重复做完整下载和校验，文档明确推荐 HTTP 下载；未为此新增缓存或后台清理。工具风险标注不是用户审批的替代，开启执行开关后仍须在实际客户端确认费用及具体外部动作。
