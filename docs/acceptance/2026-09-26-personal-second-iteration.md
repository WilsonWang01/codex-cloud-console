# 个人助理第二轮实现、验收与 Review

日期：2026-09-26。依据：[第二轮竞品对标](../competitor-benchmark-2026-09-26.md)和[统一路线图](../personal-agent-roadmap.md)。本记录只描述本地代码和模拟验收；未部署 EC2、未执行付费模型任务、未读写真实邮箱或日历。

## 本轮交付

- 个人空间增加“今日”“资料”和按空间显示的审批；今日汇总已有待处理/运行状态、最近文件及对话，文件可直达预览、下载和继续交办。工作项目的审批不再出现在个人页。
- 任务建议按当前服务状态标识邮箱/日历，缺失时可直达连接面板；上游目录受限时标记状态待确认，不把未知误判为未连接。选择任务仅填草稿。
- 共用运行时和独立 worker 都允许用户主动上传个人附件；专用模式经第二条 Unix socket 由低权限 worker 校验、存取，主服务不直接读取其私有目录。服务端限定大小、路径与数量，个人模型默认只读。资料接口只列个人工作区的普通文件，隐藏配置路径、拒绝符号链接，并以受限流式响应下载。个人上传副本不随会话删除；资料页显式确认删除且在仍被会话引用时拒绝。
- 个人事实由用户明确添加、修改和删除，存于独立状态文件；新建或恢复个人线程时提供当前事实。删除不会修改旧对话。设置页把账号、服务、事实和通知置于基础设施诊断之前。
- 用量视图修复筛选旧响应覆盖新响应，明确加载/失败/未知用量与浏览器时区；24 小时图包含首尾部分小时，并提供可读分时表、请求到运行模型及 token 的下钻、只读 JSON 导出，不导出令牌或输入正文。
- 独立调用方增加最小参考客户端：稳定业务幂等键提交、带身份的结果轮询、限流退避及显式取消。只用假 HTTP 服务端验收，未运行真实自动化。
- 自动化运行事件持久保存递增游标，现有结果接口可按 `after` 读取最近事件并标识裁剪缺口；对外只返回时间、类型与序号。没有把 JSON 状态文件误称为事务队列。
- 手机个人对话收起重复设置区，改善触控目标、面板焦点与 Escape；回看消息时不强制滚到底。运行中补充指令失败不再伪装已发送，保留输入供核对。
- 运行中默认把纯文本消息排队到本轮之后，“立即补充本轮”保持独立入口。每会话只允许一条待发消息；排队持久化，撤回时服务端原子地放回草稿。上一轮失败或控制台重启后暂停/待核对，避免自动重复执行；有排队内容时拒绝插队、归档和删除会话。列表仅返回短预览；移动端短视口收起运行中低频设置以保留发送控件。
- 外部归档通知到来时，未发送草稿和排队消息迁移为可见的本地会话；主动归档或删除则不生成额外副本。CLI 升级前可用只读探测检查初始化、账号、模型分页及线程目录，并可用候选二进制做 schema 差异检查。
- 自动化原有精确末行完成标记可选叠加工作区交付文件与 SHA-256 校验。文件缺失、为空、路径越界、符号链接或哈希不符不会被报告为完成；无法读取的校验结果保留待核对，不触发自动重试。
