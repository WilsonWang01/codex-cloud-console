# 个人事项继续跟进的模型质量验收

本轮补 P03.5/E16 的模型理解证据，不新增产品功能或第二套执行机制。使用上一轮页面实际生成的未发送草稿，先检查本机模拟响应，再执行 1 次真实 `gpt-6-sol / medium` 回合。未部署 EC2，没有开启后台任务或修改业务数据。

## 实际结果

虚构事项为“合成路线跟进”：用户记录“整理候选路线”已完成，“确认日期”未完成，等待家人确认日期；具体原回复说明没有预订或付款。

真实模型回答：

> 按你提供的记录，候选路线已整理；“确认日期”尚未完成，目前在等家人确认。原回复只是一条既有建议，不能据此认定已经预订或付款。
>
> 请补充家人确认的日期，或告诉我目前有哪些待核对的日期；核对后再决定是否预订。

回合用时约 4.4 秒，不含页面与 CLI 启动。用量为输入 11,884、输出 110、合计 **11,994 tokens**，其中缓存输入 5,248、推理输出 29；缓存和推理是子项，不再累加。完成状态和用量来自原生回合事件，不用估算字数代替。

只有用户消息、推理和最终回答，没有工具/权限请求或执行项目，没有重复整理路线或声称外部动作成功。这是 1 个同日虚构样例，不是实际跨日使用、真实业务成功率或用户有用评价；`actualCrossDay=false`、人工评价 0，不将其计为 E16 整体通过。

## 怎么复跑

```sh
npm run verify:personal-results:quality
```

默认先运行真实隔离控制台的结果页面验收，导出结构化草稿；再由固定 CLI 0.157.1 连接仅监听本机的模拟响应。页面检查通过后才写入草稿证明；来源全文指纹、字段、未完成步骤和 10 分钟有效期再次核对。不是另一份手写提示词，也不直接信任旧的文本截图。

需要真实模型时，先获得对应额度授权，再使用已经受信任的工作目录：

```sh
CODEX_PERSONAL_LIVE_APPROVED=1 \
CODEX_PERSONAL_LIVE_CWD=/path/to/already-trusted/project \
npm run verify:personal-results:quality -- --live
```

环境变量只是技术开关，不能代替人的授权；缺少既有登录或受信任目录时，在启动模型前拒绝。它不会复制登录凭据或登记新信任目录。复用现有纯运行客户端、个人助理指令、执行配置和用量记录，不新增依赖。

每次真实模式最多一个回合，120 秒上限，失败中断且不自动重试；先检查实际线程为临时、只读、无命令联网、连接器目录完整且停用。终端、浏览器、搜索、图片、记忆和派生工具按测试配置停用，任何服务器工具/权限请求拒绝并记录。模拟模式另检查实际广告工具目录；不将这个测试设置冒充所有生产会话的系统隔离。
