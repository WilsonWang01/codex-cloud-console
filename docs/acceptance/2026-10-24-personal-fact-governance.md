# P03.1 个人资料有效期与上下文保护

日期：2026-10-24，Asia/Shanghai。候选分支 `codex/p03-fact-governance` 已同步主线 `9214d42`，仍未合并或部署。此前独立上线的 `bb31129` 仅含安全修复，不包含本功能。没有写入真实个人资料或运行模型，整体 goal 保持 active。

## 实现范围

原事实管理增加启用状态、可选到期时间及用户确认时间。旧版未记录确认时间时显示未知，不倒填历史。仅用户主动填写、启用且未过期的资料进入个人任务，工作项目不读取。来源由服务器生成，不能通过请求冒充模型确认；跨页面版本冲突仍保留输入。

每次准备提供资料时保存线程绑定的内容指纹快照，不含资料正文，也不证明模型实际引用。资料更正、停用、到期或删除后，旧线程不能恢复、分叉或压缩后继续使用旧内容。来源不明的历史个人线程也需要一次明确的新上下文。新增资料或仅版本变化而内容相同不会误拦。模型启动前再次核对；已运行任务不能被承诺“忘掉”先前内容，也不会擅自中断。

“开启新上下文”先明确确认，只复制已保存的未发送草稿、附件引用与显式模型/推理/个人权限/搜索设置，不复制历史、目标或排队任务，不自动发送，原会话仍可读。相同预留标识重试不创建第二个会话、不覆盖新会话后续编辑；草稿变化、跨空间、运行任务、排队或未核对外部动作拒绝不安全切换。

模型记忆候选、引用收据、记忆历史和跨会话持续目标不在本分项中，P03/M4 未完成。

## 保存与回退

读取限 1 MiB，拒绝链接和读取期间替换。读 v1 不写磁盘，实际修改写 v2，保留未知根级/条目元数据；损坏或未知格式不覆盖。文件 0600，临时文件同步后原子替换；同进程多个 store 共用串行队列，不声称支持多实例并写。

旧后端不理解停用/有效期，不能让它静默重新注入资料。因此复用 `ops/check-task-rollback.mjs`，有 v2 数据时拒绝退到不兼容旧代码，保留新数据及当前版本等待修复，不以旧备份覆盖新资料。严格健康加入资料格式层。发布仍须重新检查空闲、备份、健康；本轮未发布。

## 后续真实页面复核

原生确认框控制中断没有被记作通过。后续改用标准 HTML 对话框，不新增依赖，默认聚焦取消，保留 Esc 退出和明确确认，后台页面不能抢占焦点。四种宽度的取消、确认、对话框边界与草稿/附件/显式运行设置保留通过实际前后端验收。

内置浏览器完整走通取消、再次确认、返回旧历史、从列表找回新草稿及刷新恢复。期间发现共用列表原来隐藏全部非当前草稿：服务器数据仍在，但新上下文离开后难以找回。修复列表共用判断，仅隐藏非当前空白草稿，有文字或附件的草稿保留在个人/工作列表，不新建另一套草稿索引。

新增实际页面回归覆盖个人草稿往返/刷新、工作文字草稿和仅附件草稿；共用函数测试同时覆盖两个空间、空白、斜杠指令、文字及附件。真实浏览器截图在忽略目录 `iab-inline-confirmation.png`、`iab-draft-reachable.png`、`iab-draft-after-reload.png`，均为合成资料，不上传正式页面或私人数据。

扩展验收时两次测试失败分别来自错误地把占位文字当成 aria-label，以及工作列表未加载完成就计数，已修正选择器和就绪等待。旧夹具未按请求目录过滤线程，已改为遵守目录契约；不将夹具产生的跨空间显示当成生产泄漏证据。

进一步审查发现，手动导入未登记的原生线程编号时，会在归属验证前调用恢复。现改为先只读查询原始线程，核对 ID、绝对目录及规范化后归属；其他空间、前缀相似目录、越界路径或未知目录均拒绝，不能先恢复再验证。新增共用函数和实际双向 HTTP 拒绝测试，核对未调用恢复或模型、未导入其他空间线程。本轮没有在生产伪造跨空间请求，也没有把风险说成已发生的真实泄漏。

显式传入未知或跨项目会话编号时，公共入口现在返回 404，不静默创建替代会话或启动任务；不传编号的正常新建保持兼容。实际 HTTP 拒绝与创建回归通过，定向检查增至 54 项。
