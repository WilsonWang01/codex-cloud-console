# Personal Agent 首批开发验收与代码 Review

日期：2026-09-26。范围：个人/工作空间、网页审批、独立 API 调用方与用量、移动布局，以及 AWS 上手文档。模型与客户端测试使用本机临时状态和模拟请求；同日随后完成受限 EC2 部署及只读线上验收，**未运行付费模型**。线上记录见末节。

## 结论

当前是已部署的**受限增量版本，不是 D1-D4 全部放行版本**。个人空间已能独立管理非 Git 对话和草稿；专用 worker 已在 EC2 安装并通过主机隔离探针，但独立 Codex 账号尚待登录，工作执行器仍有 sudo，双向文件权限、事务任务接收与硬预算仍是阻断项。外部服务可用独立令牌触发指定自动化，并按调用方范围读取结果、请求取消；尚无产物下载与经验证的 Muse/Today/Grok Bot 适配。

## 未完成与上线门槛

1. **P0：独立账号与双向权限。** 个人 worker 已在 EC2 安装，通过目录、元数据及本机端口隔离探针；尚需完成独立 Codex 登录和真实任务验收。旧工作执行器拥有 sudo，不能保证工作任务读不到个人资料，因此个人空间仅作为有明确提示的只读预览，不放入敏感资料。
2. **P0：可靠任务与成本准入。** 当前仍沿用 JSON 自动化运行存储；有单进程并发和可选已知 token 日软门槛，但没有事务接收、跨进程租约或费用硬上限。重启后的外部任务需要人工核对，不能声称恰好执行一次。部署后真实审批会使部分无人值守任务超时拒绝，应先确认任务影响和人工处理路径。
3. **P1：计量覆盖。** 请求日志默认保留 30 天，但尚无长期汇总；运行缺完整单轮快照时只记“未知”，不代表零消耗，也不等于账单。
4. **P1：外部交付契约。** 结果轮询与取消可用，但没有范围校验后的产物下载、可重放事件流或真实连接器；Muse/Today/Grok Bot 的实际接入能力未验证。外部 prompt 仍由高权限同用户执行器处理，不能交给不受信任的服务。
5. **P1：真实环境验收。** 已确认部署前无活动对话/自动化、磁盘有余量，并创建权限为 0600、可列档校验的控制台状态/配置/发布目录备份；新控制台与 Caddy 已上线并通过下述只读检查。尚未做备份恢复演练、真机/弱网测试或付费模型调用，不能据本报告宣布完整个人 Agent 上线。
