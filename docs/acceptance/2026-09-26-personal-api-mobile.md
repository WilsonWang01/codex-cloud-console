# Personal Agent 首批开发验收与代码 Review

日期：2026-09-26。范围：个人/工作空间、网页审批、独立 API 调用方与用量、移动布局，以及 AWS 上手文档。模型与客户端测试使用本机临时状态和模拟请求；EC2 只进行了只读现场核对及受限备份，**未运行付费模型或部署新版服务**。

## 结论

当前是可审查的增量版本，**不是 D1-D4 的上线放行版本**。个人空间已能独立管理非 Git 对话和草稿；专用 worker 与独立账号登录通道已编码，本机 Socket 测试通过，但 EC2 尚未安装和做权限验收。工作执行器仍有 sudo，双向文件权限、事务任务接收与硬预算仍是阻断项。外部服务可用独立令牌触发指定自动化，并按调用方范围读取结果、请求取消；尚无产物下载与经验证的 Muse/Today/Grok Bot 适配。

新增模块只承载实际边界：审批 broker、调用方与请求日志、单轮用量、结果 DTO、并发准入和通知重试；用量页延迟加载。没有引入第二套聊天引擎、数据库或独立任务模型。现有 Webhook/Heartbeat、项目与会话仍是唯一执行入口。Caddy 配置在本机缺少 `caddy` 二进制，未做语法验证；新增代理路径不能据此直接上线。

## 未完成与上线门槛

1. **P0：独立 worker 现场验收与双向权限。** 个人 worker 的代码与 systemd 模板已完成，但需在 EC2 安装、独立登录并用假秘密做目录、元数据和本机端口越权测试。旧工作执行器拥有 sudo，不能保证工作任务读不到个人资料。
2. **P0：可靠任务与成本准入。** 当前仍沿用 JSON 自动化运行存储；有单进程并发和可选已知 token 日软门槛，但没有事务接收、跨进程租约或费用硬上限。重启后的外部任务需要人工核对，不能声称恰好执行一次。部署后真实审批会使部分无人值守任务超时拒绝，应先确认任务影响和人工处理路径。
3. **P1：计量覆盖。** 请求日志默认保留 30 天，但尚无长期汇总；运行缺完整单轮快照时只记“未知”，不代表零消耗，也不等于账单。
4. **P1：外部交付契约。** 结果轮询与取消可用，但没有范围校验后的产物下载、可重放事件流或真实连接器；Muse/Today/Grok Bot 的实际接入能力未验证。外部 prompt 仍由高权限同用户执行器处理，不能交给不受信任的服务。
5. **P1：真实环境验收。** 已只读确认 EC2 控制台无活动对话/自动化、磁盘有余量，并创建权限为 0600、可列档校验的控制台状态/配置/发布目录备份；尚未做恢复演练、部署迁移、Caddy 配置检查、真机/弱网测试或付费模型调用，不能据本报告宣布线上可用。
