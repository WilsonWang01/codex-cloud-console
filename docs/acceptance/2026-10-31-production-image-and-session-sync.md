## 页面后发现的 P1 问题

用量页实际筛选本次调用方：提交 2、受理 1、同键重放 1、已知 token 34,289、模型回合 1、处理中 0；1280px 桌面和 390px 手机尺寸均能查看，后者没有横向溢出。原生图片端点在内置浏览器实际加载，手机尺寸展示完整图片；不是实体手机证据。

但直接打开本次自动化对话后，页面回退项目，显示没有对话。随后对账发现旧 API 验收会话的索引缺失，不能把这一页面记为成功，也不能宣布数据保持。

根因在 `syncAppServerThreads -> upsertAppServerThreads`：`thread/list` 按项目目录筛选，且最多读取 120 条；工作树目录不等于项目根目录，分页也不是完整历史。代码却把没有列出的已有线程视作删除，直接移除其本地会话索引。这会使历史入口、显式模型和空草稿的索引不可达。用户主动归档、删除是另一条流程，不能由列表缺项推断。

首次页面前对账还发现一条旧去重键被移除。其到期时间为 `2026-10-30T18:31:50.418Z`，早于本次执行，符合既有 24 小时缓存策略；原任务和私有结果仍在。这项正常过期与随后发生的索引缺失必须分别记录，不能用过期机制解释或忽略丢失的会话索引。
